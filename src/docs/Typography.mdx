## Typography Roles

### Headlines (Serif)
- Short 
- Punchy 
- Emotional 
- Never more than 1-2 lines 

"Take the long way."

### Body (Sans)
- Clean, readable, slightly relaxed 
- Conversational tone 

### Labels / UI (Sans Medium)
- Slightly tighter tracking 
- Clear hierarchy 

### Accent (Script)

- Used like a highlighter, not a paragraph:  
"worth it",
"don't skip this"

## Usage Guidelines 

### Hierarchy Rules 

- 1 dominant headline per screen
- Clear visual drop between levels
- Don't stack multiple large serif headers (gets heavy fast)

### Spacing + Rhythm 

- Generous whitespace = premium feel 
- Line height slightly loose for readability
- Avoid cramped layouts at all cost 

### Contrast Pairing 

Best combos:
- Serif headline + Sans body ✅
- Sans UI + Script accent ✅

Avoid:
- Script + Script ❌
- Serif for body text ❌ (too heavy)

### Alignment Style

- Mostly **left-aligned**
- Occasional **centered hero text**
- Avoid justified text (kills the vibe)

### Case Usage 

- Headlines: **Title Case or Sentence Case**
- UI labels: **Sentence case**
- Avoid ALL CAPS except:
- small labels
- navigation tags 

### Letter Spacing
- Headlines: slightly tight (-1% to -2%)
- UI labels: slightly loose (+2% to +4%)

## Emotional Typography Rules

Every text block should feel:
- Effortless
- Slightly imperfect
- Human, not system-generated 

If it feels like:
- ❌ a SaaS dashboard
- ❌ a banking app

...it's wrong.
