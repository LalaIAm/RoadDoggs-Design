## Accessibility Guidelines

We’re not sacrificing usability for aesthetics. RoadDoggs should feel cool and be readable at 2am on 3% battery. 

### Contrast Rules
- Minimum WCAG AA (4.5:1) for all body text
- Large text: minimum 3:1
- Buttons (especially Burnt Orange) must pass contrast on both light & dark

### Key Pairings (Safe Combos)

- Road Black on Dust White ✅
- Dust White on Road Black ✅
- Burnt Orange on Road Black ✅
- Road Black on Faded Sand ✅

### Avoid These Combos 

- Burnt Orange on Faded Sand ❌ (low contrast)
- Olive on Dust White ❌ (too soft)
- Gray on Gray ❌ (obvious villain behavior)

### Color Blind Considerations 

- Never rely on color alone for meaning
- Pair semantic colors with:
-- icons
-- labels
-- subtle patterns

Example:

- Error = red + icon + message
- Not just red text floating in space

## Usage Guidelines

### Color Hierarchy Rule (super important)

**1 Primary Accent at a time**

If everything is highlighted... nothing is.

- Burnt Orange = main action only
- Secondary accents = supporting roles 
- Neutrals = everything else 

### CTA Rules
 
- Primary buttons = **Burnt Orange**
- Hover = **Muted Rust**
- Disabled = **Asphalt Gray** 

### Background Strategy

- Default = **light (Dust White)** for content 
- Switch to **dark (Road Black)** for: maps, immersive views, route exploration 

### Card Design 

- Backgrond: Dust White or Faded Sand
- Border: subtle (or none)
- Accent: small hint of orange or olive 

Think:
- travel journal, not SaaS dashboard

### Map + UI Balance 

Maps are visually loud. UI should chill.
- Use dark map + minimal UI chrome 
- Let route color (orange) pop clearly
- Avoid stacking too many colors on map

### Emotional Color Use 

Each color should *feel* like something:
- Orange -> action / movement / "go"
- Olive -> calm / nature / scenic 
- Blue -> pause / balance 
- Neutrals -> grounding / readability
