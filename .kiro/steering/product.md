# RoadDoggs Guide — Product Overview

RoadDoggs is a road trip planning app that turns the friction of trip planning into a fast, personalized experience. It generates custom routes (not "itineraries"), complete with daily drive time, suggested spots, lodging ideas, and cost estimates — in minutes, not hours.

## Core Concept

The product is built around an AI "Co-Pilot" that helps users build, tweak, and explore their routes conversationally. The experience should feel like a well-traveled friend giving advice, not a SaaS dashboard generating data.

## Brand Vocabulary

Use these terms consistently in UI copy, labels, and component content:

| Use this            | Not this                   |
| ------------------- | -------------------------- |
| Route               | Trip / Itinerary           |
| Game Plan           | Itinerary                  |
| Spots               | Stops / Points of Interest |
| Finds               | Recommendations            |
| Co-Pilot            | AI Assistant               |
| Tweak               | Edit / Modify              |
| Build / Map Out     | Generate                   |
| Spend               | Budget                     |
| Picks / Suggestions | Recommendations            |

**Banned words:** itinerary, optimize, algorithm, generate, user, platform, solution, leverage.

## Design Principles

- Momentum over friction — every interaction should feel like forward motion
- Emotion first, utility second — design for excitement and curiosity before efficiency
- Guided, not controlled — suggestions feel like a smart friend, not a rigid system
- Visual storytelling — layouts should feel like a travel journal, not a data table
- Personal by default — nothing should feel generic

## Tone

Confident, slightly rebellious, concise, and human. Short punchy sentences. Natural spoken language. A little rough around the edges on purpose.
